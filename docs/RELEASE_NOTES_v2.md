# V2.0.0 — 탐지 검증 및 탐색 구조 개선

V1의 자기장 기반 탐지와 탐색을 기반으로, 탐지 후보 검증과 이동·순찰·복구 역할을 분리한 버전입니다.

## 주요 변경

- 후보 주변 공간·시간 자기장을 재검사하는 학습된 Candidate Verifier CNN 추가.
- 탐지 후보 선택, 증거 누적, 핑 확정, 동일 좌표 시간 변화 검사 분리.
- 자기장 모델 교체 인터페이스와 이동·방향에 따른 합성 동적 신호 추가.
- 로봇 반경을 고려한 일반·정밀 경로 계획, 좁은 통로 진입 및 실패 경로 관리.
- 구역별 순찰 주기, 미관측 목표 재시도 관리, 반복 정체 시 다른 구역 이동.
- 짧은 직선 왕복이 반복될 때 다음 반전 동작을 실행 전 취소.
- 직사각형 장애물 겹침 방지, 정확한 거리 교점 계산과 관측 벽 연결.
- 로봇 인식 화면의 순찰 구역·목표·계획 경로 및 PC용 앱 선택 메뉴.
- 기본 실행에 필요한 모델과 별도 노이즈 대응 실험 모델 포함.

## 시작하기

```powershell
python -m pip install -r requirements.txt
python local_apps_v2/open_apps_v2.py
```

Streamlit은 `streamlit run app_v2.py`, FastAPI는 `uvicorn server_v2:app_v2 --host 127.0.0.1 --port 8000`으로 실행합니다.

후보 CNN의 저장된 합성 테스트 F1은 95.92%입니다. 이는 전체 탐지·구조 성공률이나 실측 성능이 아닙니다. 최근 이동 검사는 6개 조건의 각 800 timestep, L자 통로 12개, 순찰 환경 2개에서 수행했습니다.

`v1.0.0`은 기존 main을 보존합니다. V2는 `v2` 브랜치와 `v2.0.0` 태그로 공개하며, main과 Render 서비스는 이번 Release에서 전환하지 않습니다.
