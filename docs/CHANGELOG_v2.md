# V1 → V2 변경 사항

V1 기준은 기존 공개 `main`의 `f2063270f0294cfcef96e2071dda1f36f3e60299`입니다. `v1.0.0`은 그 시점을 보존합니다. V2는 별도 `v2` 브랜치의 코드입니다.

| 항목 | V1 | V2 |
|---|---|---|
| 자기장 계산 | 센서 구현에 결합 | 교체 가능한 모델 인터페이스와 legacy/enhanced 구현 |
| 사람 신호 | 기존 합성 시간 변화 | 이동 속도·방향과 위치에 따른 동적 합성 성분 추가 |
| 탐지 후보 | 기본 CNN의 결과 중심 | 후보 선택과 별도 학습된 패치 검증 CNN 추가 |
| 핑 결정 | 확률·지속·시간·거리 조건 | 후보 추적, 증거 누적, 안정성, 중복 억제와 확정 판단 분리 |
| 추가 변화 검사 | 기존 예측 잔차 | 동일 공간 좌표의 시간 변화 검사 경로 추가 |
| 거리 측정 | 0.5m 간격 표본 검사 | 광선과 직사각형의 교점 계산 |
| 벽 | 직사각형끼리 겹침 가능 | 겹침 방지 배치, 관측 직선 연결 |
| 경로 | 거친 지도와 행동 보정 | 로봇 반경을 고려한 0.5m 경로 + 0.25m 정밀 경로 |
| 제어 | 고정 회전·전진 및 회전 누적 후 강제 전진 | 목표 방향 회전, 짧은 안전 전진, 실패 경로·복구 관리 |
| 순찰 | 거리·방문 횟수 점수 중심 | 8m 구역별 주기와 가까운 미방문 목표 우선 |
| 반복 이동 | 기본 정체 보정 | 미관측 목표 보류, 다른 구역 이동, 짧은 왕복 실행 전 취소 |
| 인식 화면 | 센서 지도·추정 핑 | 직선 벽, 순찰 방문 구역·목표·계획 경로 추가 |
| 구조 판정 | 4.5m 신호 활성 범위, 한 명 처리 후 신호 소모 | 6.5m 활성 범위, 신호 유지, 여러 명·나중에 접근한 사람 처리 |
| 코드 접근점 | 보드 중심 연결 | `RobotObservation` 기반 분류 함수와 평가/구조 연결 역할 명시 |

## 머신러닝과 제어를 구분해서 해석하기

V1에도 자기장 변화 예측기, 사람 분류 CNN과 학습된 탐색 정책이 있습니다. V2에서 추가한 후보 검증 CNN은 별도로 학습된 모델입니다. 순찰 주기, 정밀 경로 계획, 탈출과 짧은 왕복 방지는 규칙 기반 제어입니다.

## 성능 비교 시 주의할 변경

- 구조 반경 증가 때문에 구조 인원 증가를 탐지 정확도 증가와 동일하게 해석할 수 없습니다.
- 벽 겹침 방지로 난수 사용 순서와 배치가 달라집니다. 같은 seed만 지정해 V1/V2가 동일 환경이라고 가정하면 안 됩니다. 배치와 행동 조건을 별도로 고정해야 합니다.
- 탐색 중 관측률, 후보 분류 정확도, 실제 사람 발견률, 핑 위치 오차와 구조 성공률은 다른 지표입니다.
- 최근 회전·짧은 이동 감소 수치는 V2 내부 수정 전후 검사입니다. V1 대비 개선율이 아닙니다.

## 버전 관리

`main`과 기존 Render 배포는 이번 공개에서 변경하지 않습니다. V2의 실행 파일은 `_v2.py` 이름을 사용합니다. 추후 `main`에 통합할 때는 Render 시작 명령과 실행 파일 이름도 함께 전환해야 합니다.
