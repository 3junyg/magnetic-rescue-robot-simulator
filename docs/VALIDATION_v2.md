# V2 학습 및 검증 기록

## 후보 검증 CNN의 저장된 학습 결과

`models/candidate_verifier/best_candidate_verifier_v2.json`과 같은 이름의 `.pth`를 포함합니다. 현재 체크포인트는 저장된 round4 모델입니다. 마지막 단계는 6 epoch이며, 이전 추가 학습 단계를 이어받았습니다. 전체 학습이 6 epoch만으로 수행됐다는 의미는 아닙니다.

입력은 최근 8시점, 5×5칸, 8채널의 자기장 패치와 로봇 이동 특징입니다. 배경 제거 3축, 동일 좌표 시간 차이 3축, 관측 여부와 비교 가능 여부를 사용합니다. 공간 2D CNN과 시간 1D CNN을 결합합니다.

후보에서 실제 사람이 6.5m 이내면 양성, 9m 이상이면 음성으로 라벨링하며 6.5~9m 사이는 제외합니다. 실제 좌표는 라벨에 사용되고 학습 입력에는 넣지 않습니다. 따라서 후보 검증은 정확한 좌표 일치가 아니라 주변 사람 존재 분류입니다.

| 구분 | 샘플 | 에피소드 |
|---|---:|---:|
| 학습 | 26,227 | 162 |
| 검증 | 2,857 | 18 |
| 테스트 | 2,859 | 18 |

에피소드 단위로 분리하고 초기 정규화는 학습 데이터에서 구합니다. 추가 학습은 기존 정규화 값을 유지합니다. 학습에는 합성 환경, 금속 군집, 사람 없는 환경, 여러 사람과 어려운 오분류 사례를 포함했습니다. Cross Entropy, AdamW, 클래스 균형 샘플링과 어려운 음성 사례 재가중을 사용했습니다. 검증 정밀도 95% 조건 아래 재현율을 우선해 모델·임계값을 선택했습니다.

| 저장된 테스트 지표 | 값 |
|---|---:|
| Accuracy | 98.25% |
| Precision | 95.61% |
| Recall | 96.24% |
| F1 | 95.92% |
| TN / FP / FN / TP | 2,221 / 27 / 23 / 588 |
| 사용 임계값 | 0.425 |

이 수치는 합성 후보 분류 테스트입니다. 전체 사람 발견률, 핑 위치 정확도, 구조 성공률이나 실제 센서 성능으로 읽으면 안 됩니다. 동일 테스트가 여러 학습 라운드에서 반복 확인됐으므로 추가 비교에는 새로운 독립 테스트 세트가 필요합니다. 최근 이동·벽 변경 이후의 전체 탐지 성능을 새로 입증한 기록도 아닙니다.

## 최근 이동 코드 검사

아래는 해당 V2 소스에서 저장한 로컬 headless 기록입니다. 전체 중간 추적 대신 요약과 작은 최종 결과 파일을 배포합니다.

- `short_backtrack_navigation_v2`: 3종 환경 × 2개 seed(73, 99), 각 800 timestep. 예정된 짧은 왕복 동작을 실행 전 취소한 횟수는 합계 11회, 허용된 위치에서 실제 벽 내부로 진입한 횟수는 0회입니다. 800 step 시점 관측률 범위는 87.625~94.042%입니다.
- `short_backtrack_narrow_final_v2`: 폭 2.6/2.8/3.2/4.0m와 seed 11/73/99를 조합한 L자 통로 12개 모두 통과했습니다. 전진 실패와 벽 내부 진입은 각 0회였습니다.
- `short_backtrack_patrol_v2`: seed 73의 좁은 연결 통로/무작위 환경을 각 2,200 timestep 실행했습니다. 각각 접근 가능한 150개 구역을 모두 방문했습니다. 첫 전체 방문은 990/1,177 timestep이며 실제 벽 내부 진입은 0회입니다.
- 벽 생성은 3개 환경 × 10개 seed에서 개수 유지와 겹침 방지를 확인했습니다.

벽 내부 진입 0회는 모든 충돌 시도나 모든 불필요한 움직임이 없다는 의미가 아닙니다. 경로를 거부하거나 짧게 움직인 경우는 별도 지표입니다. 8m 구역 전체 방문은 모든 연속 좌표를 지나갔다는 의미도 아닙니다.

출판용 파일만으로 구문·모델 로드·관측 경계·headless·Reset/Randomize·화면 렌더링을 확인하는 명령은 다음과 같습니다.

```powershell
python -m evaluation.verifier_smoke_v2
```

배포 폴더에서 위 검사를 다시 통과했습니다. Streamlit 화면 초기화와 기본 모델 로드, 선택 모델 로드, 실제 로컬 FastAPI 서버의 HTTP·정적 파일·WebSocket 시작도 확인했습니다. 사용한 환경은 Python 3.12, Streamlit 1.62.0, NumPy 2.4.6, Matplotlib 3.11.0, PyTorch 2.13.0, FastAPI 0.141.1, Uvicorn 0.52.4입니다. requirements는 허용 범위를 지정하며 모든 조합을 시험한 의미는 아닙니다.

상세 재실행 방법은 루트 README에 있습니다. 원시 센서 데이터와 대용량 추적은 포함하지 않으며, 다시 실행하면 `evaluation/results/`에 저장할 수 있습니다.

## 연구 해석 범위

금속·사람의 물성과 자기장 반응 비율은 실측 보정되지 않은 합성 설정입니다. 수중 전달을 정밀 해석하지 않으며 자기장 신호와 노이즈에 관한 연구 가정을 유지합니다. 로봇 자신의 위치 추정도 이상적으로 가정합니다.

전체 탐지 평가에는 새 seed·고정 배치·동일 구조 반경·독립 노이즈 조건을 사용하고, 핑 정밀도와 사람 발견률, 위치 오차, 이동 거리, 재방문과 완료 시간을 함께 기록해야 합니다. 단일 seed 결과를 일반 경향으로 주장하지 않습니다.
